# Forest Car Game

A simple racing game played in a forest where you race against other cars and earn points.

Live Game
https://cargame-rouge.vercel.app/

Controls

Left/Right Arrow Keys - Move A/D - Move Space - Boost

Features

Forest theme Racing cars Obstacles Boost Points Difficulty increases every level Easy to play Runs directly in the browser

Built With

HTML CSS JavaScript

About

Built this game to improve my JavaScript skills, learn about car physics and collisions, and develop browser-based games .

AI Use

Used some AI assistance while developing and debugging the code, but the game was primarily created by me
